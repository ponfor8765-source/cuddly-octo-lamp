# Сборка настоящего `.jar`

В этой среде нет Gradle и нет доступа к Maven-репозиториям, поэтому финальную компиляцию Minecraft/NeoForge должен выполнить компьютер, где есть интернет.

## Windows

1. Установи Java 21.
2. Распакуй этот проект в обычную папку.
3. Запусти `build.bat`.
4. Скрипт автоматически скачает Gradle 8.10.2.
5. Gradle скачает Minecraft/NeoForge зависимости и соберёт проект.
6. Готовый мод появится в:

`build\\libs\\`

Используй `.jar`, в имени которого нет `-sources`.

## Важно

Первый запуск требует интернет, потому что Gradle должен получить build-инструменты и зависимости NeoForge/Minecraft.
