# World Ender: Genesis Rift Core (NeoForge 1.21.1)

Ядро разлома, которое создаёт мощный пространственный импульс, изменяет ландшафт вокруг, оставляет кратер с порталом и открывает путь в новое измерение **Genesis** со своими биомами, рудами, мобами и структурами.

> **Статус:** исходники и ресурсы прошли локальные структурные проверки. Полная Gradle-сборка и запуск Minecraft пока заблокированы отсутствием Gradle/NeoForge-зависимостей в текущей среде; это явно отмечено, чтобы не выдавать непроверенное за готовый мод.

## Как получить .jar (выберите один способ)

**A. GitHub Actions (проще всего, ничего ставить не нужно)**
1. Создайте пустой репозиторий на github.com, загрузите в него содержимое этого архива (папка `worldender` внутри архива, её содержимое в корень репозитория).
2. Вкладка **Actions** -> workflow **Build mod** -> дождитесь зелёной галочки.
3. Откройте запуск -> блок **Artifacts** -> скачайте `worldender-jar`. Внутри будет `worldender-1.0.0.jar`.

**B. Локально**
1. Поставьте JDK 21 и Gradle 9.x (или возьмите официальный MDK NeoForge 1.21.1 ModDevGradle и положите в него `src/`, `build.gradle`, `gradle.properties`, `settings.gradle` из этого проекта, тогда `gradlew` уже есть).
2. В папке проекта: `gradle build`.
3. Готовый файл: `build/libs/worldender-1.0.0.jar`. Первая сборка долгая: Gradle скачивает Minecraft и NeoForge.

## Установка
Minecraft **1.21.1** + NeoForge **21.1.x** + Java 21. Положите jar в папку `mods`. Мод нужен и на сервере, и на клиенте.

## Как играть
- **Ядро Разлома Генезиса** (вкладка «World Ender» или рецепт из аметистовых осколков, осколков эха, незеритовых слитков и звезды Незера). Поставьте и нажмите ПКМ или подайте редстоун-сигнал.
- Отсчёт (по умолчанию 12 с): усиливаются звуковой сигнал, спираль искр, столб света, молнии и визуальная дрожь камеры.
- Импульс разлома: белая вспышка, облако частиц, ударная волна идёт по земле и изменяет ландшафт (деревья, постройки и вода в зоне воздействия), центр превращается в кратер. Мобы удаляются из зоны импульса, игроки получают только визуальный/физический эффект отбрасывания без урона.
- В центре кратера появляются **Врата Генезиса**. Войдите в портал, чтобы попасть в Genesis. Обратные врата строятся на той стороне автоматически.
- Ядро разлома не работает в Genesis и в мирах без открытого неба (Незер, Энд).

## Измерение Genesis
- Вечная ночь, светящиеся биомы: **Glow Plains, Lumen Forest, Crystal Wastes, Void Marsh**.
- Руды: **Lumenite** (самоцвет), **Voidsteel** (сырьё для слитка и инструментов), **Aurorite** (осколки).
- Мобы: **Void Stalker** (телепортируется при ударе), **Lumen Boar** (светящийся кабан), **Aurora Spider** (укус подсвечивает и поднимает).
- Структуры с сундуками: **Obelisk**, **Ring** (круг монолитов), **Tower** (башня с лестницей; в редком луте есть ещё одна ядро разлома).
- Инструменты: меч и кирка из пустотной стали.

## Настройки
Файл `config/worldender-common.toml` (появляется после первого запуска):
- `blastRadius` (по умолчанию **128**, максимум 512): радиус импульса. Чем больше радиус, тем больше серверной работы.
- `craterDepth`, `countdownSeconds`, `waveSpeed`.
- Урон игрокам отключён и отдельной настройки для него больше нет.

## Оговорки
- Импульс разлома выполняется порциями: сервер за тик обрабатывает ограниченное число колонок. Это сделано для контроля пикового CPU-нагрузки. Если сервер остановить посреди импульса, незавершённая операция не возобновится автоматически.
- Возврат из Genesis всегда ведёт в обычный мир (Overworld), к ближайшему порталу рядом с теми же координатами.
- Все текстуры нарисованы процедурно (скрипты в `tools/`): `python3 tools/gen_assets.py` и `python3 tools/gen_data.py` пересоздают ресурсы и данные.
